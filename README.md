# Deep Learning Lab

A collection of Deep Learning laboratory assignments covering neural networks, computer vision, sequence modeling, transfer learning, NLP, and audio applications.

## Assignments

| Assignment | Topic |
|---|---|
| [01](Assignment-01/) | Fashion-MNIST image classification |
| [02](Assignment-02/) | Single-Layer Perceptron for binary classification |
| [03](Assignment-03/) | Bank Marketing classification and neural-network training experiments |
| [04](Assignment-04/) | LSTM-based stock-price forecasting |
| [05](Assignment-05/) | Comparison of RNN, LSTM, and GRU for sequence classification |
| [06](Assignment-06/) | CNN-based tomato disease classification |
| [07](Assignment-07/) | Transfer learning with AlexNet, VGG16, ResNet50, and EfficientNetB0 |
| [08](Assignment-08/) | Pre-trained BERT for sentiment analysis using SST-2 |
| [09](Assignment-09/) | Image classification using a Vision Transformer and a CNN |
| [10](Assignment-10/) | Deep learning for audio classification with speech-to-text and text-to-speech |

Each assignment is kept in its own folder with the practical document and implementation notebook or script. Check the files in each folder for assignment-specific details and instructions.

## Tools and Libraries

Python, TensorFlow/Keras, PyTorch, Torchvision, Hugging Face Transformers, NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.

## How to Use

Open an assignment folder and run its notebook in Jupyter Notebook or Google Colab, or run the included Python script where applicable. Some assignments download datasets or pre-trained weights automatically; others may require local data. Follow the instructions in each assignment folder.
