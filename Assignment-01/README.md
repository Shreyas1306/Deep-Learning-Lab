# Assignment 01 – Fashion-MNIST Classification

## Aim

To implement an image classification model using the Fashion-MNIST dataset
and evaluate its performance.

## Description

This assignment implements a neural network using TensorFlow/Keras to
classify Fashion-MNIST images into their respective clothing categories.

## Contents

- `Assignment-01.docx` – Assignment problem statement.
- `Assignment-01.ipynb` – Complete implementation with preprocessing,
  model training, evaluation, and predictions.

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## Dataset

The Fashion-MNIST dataset is loaded directly using TensorFlow/Keras.
No separate dataset download is required.

## How to Run

Open `Assignment-01.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab
and run the cells sequentially.

## Results

The notebook contains the model evaluation results and sample predictions.

## Conclusion

The trained neural network successfully learns to classify images from
the Fashion-MNIST dataset into 10 different clothing categories.
